# Sprime

基于 Rime（trime / librime）的 Android 输入法，内嵌 AI 助手：在输入法内直接提问与取用回答，不新开窗口、不改变键盘高度。

## AI 能力

- **多轮对话**：面板内可连续追问，上一轮问答会带进下一次请求（自动截断到 20 条 / 8000 字）
- **快捷动作**：翻译 / 润色 / 总结 / 解释 / 回复 / 续写，作用于选区、整个输入框、光标前文或剪贴板
- **上下文范围**：整段输入框内容（最多 4000 字）自动作为上下文，可选带上剪贴板
- **自动填入**：可开启「回答完成后自动填入」；填什么由模型决定，模型用 `<insert>…</insert>` 标出要输入的那段，其余解释不会进输入框
- **PII 脱敏**：发送前按类型屏蔽手机号、身份证、银行卡、邮箱
- **思考过程**：支持 `reasoning_content`（DeepSeek R1 等），以浅色小字显示，默认收起、点击展开
- **流式回答**，可随时停止、重试、复制、插入、撤销

## 关键决策（摘要）

- 形态：固定总高 IME（竖屏 338dp）+ 常驻 48dp 顶栏 + AI 整页切换，insets 全程不变
- 外部可观测性：仅"输入法包名 + 恒定高度"，不新增窗口、不申请 overlay 权限
- 基线：trime v3.3.12；applicationId = com.sprime.ime；Kotlin 包保留 com.osfans.trime
- AI：BYOK + OpenAI 兼容 + 预设（默认 DeepSeek），默认不存历史、不上传剪贴板、密码框禁用
- 分发：GitHub 开源 + 自签 APK
